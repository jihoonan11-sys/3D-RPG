# 성채 RPG (3D 온라인 커뮤니티 RPG)

브라우저에서 실행되는 3D 중세 판타지 RPG입니다. 안전한 성채에서 생활하고, 성 밖으로 나가 몬스터를 사냥하는 것이 핵심입니다.

현재 진행 상황: **PHASE 3 완료** (성채, 성 밖 초원과 숲, 기본 몬스터). 다음은 PHASE 4 (전투)입니다.

## 실행 방법 (GitHub Pages)

1. 이 폴더의 **모든 파일과 폴더**를 GitHub 저장소에 올립니다. (`index.html`이 저장소 맨 위에 있어야 합니다.)
2. 저장소 **Settings → Pages**에서 Branch를 `main`, 폴더를 `/ (root)`로 선택하고 Save를 누릅니다.
3. 1~2분 뒤 `https://내아이디.github.io/저장소이름/` 링크로 접속합니다.

파일을 고쳐서 다시 올린 뒤 화면이 바뀌지 않으면 **Ctrl+Shift+R**(강력 새로고침)을 누르세요.

> 이 프로젝트는 여러 파일로 나뉘어 있어서 `index.html`을 컴퓨터에서 더블클릭해 열면 동작하지 않습니다. 꼭 GitHub Pages 링크로 여세요.
> 컴퓨터에서 직접 시험하려면 이 폴더에서 `python -m http.server 8000`을 실행하고 `http://localhost:8000`으로 접속하면 됩니다.

## 조작

- 이동: W A S D (또는 방향키), 달리기: Shift, 점프: Space
- 카메라: 화면을 클릭한 뒤 마우스 이동 (ESC로 해제), 확대/축소: 마우스 휠

## 폴더 구조

```text
index.html          시작 페이지 (3D 라이브러리 주소와 오류 표시 화면)
client/             브라우저에서만 쓰는 코드 (화면, 입력, 3D)
shared/             화면과 상관없는 게임 규칙 (나중에 서버도 같이 사용)
assets/             직접 만든 3D 모델(.glb) 등을 넣는 곳
docs/               설계 문서
```

자세한 설명은 `docs/ARCHITECTURE.md`를 보세요.
